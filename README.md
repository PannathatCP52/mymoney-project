## วิธีการติดตั้งและรันโปรเจกต์
1. โหลดโค้ดลงเครื่อง
2. พิมพ์คำสั่ง `npm install` เพื่อติดตั้งเครื่องมือ
3. สร้างไฟล์ `.env` และใส่รหัสผ่าน `MONGO_URI=ลิงก์ของคุณ`
4. พิมพ์คำสั่ง `node server.js` เพื่อเปิดเซิร์ฟเวอร์
